# ADR 0009: Rename devpelopment-setup.md to development-setup.md

## Context

The repository contains a setup guide named `devpelopment-setup.md` under `docs/to_integrate/`, which includes a typo in the filename and is intended to become a primary development setup document. The misspelling causes confusion and looks unpolished.

## Decision

- Rename `docs/to_integrate/devpelopment-setup.md` to `docs/development-setup.md` as part of integrating the document into the new IA.
- Update references in other docs (e.g., `README.md`, `AGENTS.md`) to point to `docs/development-setup.md`.

## Consequences

- Improves discoverability and professionalism of the documentation.
- Requires updating any links or references to the old filename.

## References

- `docs/development-setup.md` (target development setup guide)
- `README.md` and `AGENTS.md` (links to setup docs)
